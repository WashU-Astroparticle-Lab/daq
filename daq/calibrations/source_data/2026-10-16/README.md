# Filter-offset-corrected low-band calibration — 16 October 2026

**0.1–2.1 GHz is calculated by filter offset. These are estimates of unfiltered power,
not new direct unfiltered amplitude sweeps.** The original filtered curve shape is preserved.

Inputs (measurement files are immutable; all files are byte-hashed inside the NPZ):

| File | Provenance / role |
| --- | --- |
| low_filtered_power.csv | Unchanged Oct 2 low_power.csv: 101 frequencies, 50 amplitudes each, TWO cascaded VLFX-2500+ filters. |
| low_anchor.csv | Unchanged Oct 12 direct unfiltered scan: 101 frequencies, amplitude 0.1, 2 s holds. |
| gap_power.csv | Unchanged Oct 12 direct unfiltered 2.1–2.5 GHz sweep, 50 amplitudes, 0.5 s holds. |
| high_power.csv | Unchanged Oct 2 direct unfiltered 2.5–9 GHz sweep, 100 amplitudes, 0.5 s holds. |
| low_amplitude_checks.csv | Independent Oct 12 five-amplitude checks at 0.1, 1 and 2.1 GHz; not used to fit offsets or curves. |
| high_validation.csv | Independent nine Oct 12 high-band checks; commands used the unchanged high-band model. |
| filter_pair_comparison.csv | Same-day two-filter versus no-filter comparison at five frequencies. Context only; not used to fit the 101 offsets. |
| interpolation_policy.json | Frequency coverage, historical switch diagnostics, correction assumptions and reference-plane metadata. |

The builder calculates the filtered power at amplitude 0.1 by interpolating dBm linearly
between its two neighboring log-amplitude samples (both must be unflagged). The offset is
the direct unfiltered amplitude-0.1 power minus this interpolated filtered power. Add the
same offset to all 50 original powers at that frequency. No validation point is fitted.

Reproducible output tables, regenerated by build_power_calibration.py:

- low_filter_offsets.csv: all 101 offsets, the two original bracket powers/amplitudes,
  interpolation weight, unfiltered anchor and negative-offset flag.
- low_corrected_power.csv: all 5,050 corrected powers alongside original filtered powers,
  offsets, original acquisition flags, reading counts and sweep IDs. No raw powers overwritten.

The correction assumes an amplitude-independent dB shift at each frequency and comparable
setups. It includes possible session drift and cable/path changes; it is not an isolated
filter insertion-loss measurement. Negative offsets at 140, 880 and 960 MHz are retained,
flagged and discussed, not forced positive. No correction to the noise floor or spur spectrum
is inferred from the main-tone correction.

Selection: corrected low-band nodes include 2.1 GHz; direct gap nodes are 2.12–2.48 GHz;
direct high nodes are 2.5–9 GHz. This gives 251 nodes and 19,100 source rows (5,050 corrected,
14,050 direct). The direct 2.1 GHz gap sweep is retained as an independent overlap check.
The direct gap 2.5 GHz endpoint is retained but the original high-band 2.5 GHz model is used.

Quality floors retain the previous rule: above every acquisition flag or absolute residual
>0.5 dB from a high-amplitude 20 dB/decade reference. In the low band that reference screens
quality only; it does not replace the curve. Supported corrected samples must be strictly
monotonic, enabling an unambiguous inverse. Below the floor the runtime warns and extends
20 dB/decade from the floor. All original weak/flagged samples remain in the corrected table
and NPZ, but are not promoted to supported inverse knots.

Git newline conversion is disabled for source and derived CSV/JSON files. Raw spectra and
original XLS timing/amplitude logs remain in the laboratory collection. Source/receiver
times were matched after acquisition, without a hardware handshake. Power is at analyzer
input, without cable-loss correction. See docs/power_calibration_update.md for details.
